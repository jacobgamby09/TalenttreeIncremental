# Otte visuelle retninger til talenttræ-spillet

Genereret med det indbyggede imagegen-værktøj. Billederne er stilkoncepter, ikke færdige gameplay-specifikationer.

## 1. Nordisk minimalisme

Fil: 01-nordisk-minimalisme.png

Use case: ui-mockup. Create ONE beautiful, polished landscape game-screen concept, not a collage. This is an incremental fantasy RPG where the entire world IS a sprawling connected talent tree. The node network occupies most of the image, with spacious readable clusters and clear connections, branching in different directions, no conventional landscape with a tiny skill menu. Square illustrated nodes represent activities, upgrades, enemies, craftable equipment and building slots. Large cluster titles with local XP bars. Show WOODCUTTING with Oak -> Birch -> Willow, small adjoining speed/yield upgrades; MINING with Copper -> Tin; BLACKSMITH with a Copper Armor node costing '5 copper bars'; HOME with a few filled and empty building slots. COMBAT includes an enemy node next to a PLAYER node, each with health bar below and a partially illuminated perimeter indicating attack charge, plus compact ATK / HP / DEF / SPD stats. Only ONE activity runs at a time: combat here, resource skill nodes are idle. Include a short dungeon chain terminating at a larger guardian node. Some future connections and silhouetted nodes peek out of unexplored space; elsewhere an unexpected newly discovered small cluster unfurls with luminous new connections. Convey early exploration of a huge world, not a fully revealed symmetrical tech tree. Restrained readable English labels, coherent hierarchy, game-ready visual design. No device frame, no watermark, no giant marketing title. Each image must feel like a plausible actual playable game UI while strongly expressing its specified art direction.
Art direction: Nordic minimalist editorial UI. Warm ivory background, charcoal typography, sage green and muted terracotta accent colors. Flat geometric icon illustrations, thin tidy connector lines, generous whitespace, crisp square tiles. Asymmetrical airy graph, subtle pale mist at uncharted edges. Sophisticated understated Danish boardgame aesthetic. Small top-left concept label '01 / NORDIC'. Keep distinctly light and restrained, not generic dark fantasy.
